# Support

Report reproducible defects through the repository issue tracker. Include:

- RaftSim version and the SHA-256 archive hash;
- operating system, CPU, GPU, display resolution, and input device;
- game mode, South Fork section/rapid, flow band, and seed if visible;
- exact steps, expected result, actual result, and whether a fresh profile reproduces it;
- the local Unreal log or crash context after reviewing it for personal information.

Do not use RaftSim output for river navigation or emergency decisions. For real-world
rafting incidents, contact local emergency services and qualified river professionals.

Security-sensitive reports should not publish credentials, signing keys, store tokens,
or personal data. Contact the repository owner privately before disclosing a credible
security issue.
