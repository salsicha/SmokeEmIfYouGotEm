# Troublemaker reference follow-up

September 7, 2026 local time. Reference-only, not geographic/layout acceptance.

The [American River Resort description](https://www.americanriverresort.com/adventures/whitewater-rafting-on-the-american-river/troublemaker)
places Troublemaker beside its property on a broad river bend. Its quoted route
description identifies an upstream boulder garden, a drop, a left-side S-channel,
a diagonal wave and Gunsight Rock. It credits Coloma Club for that description.

description is substantially the same wording, so do not count these as two
independent rock-layout observations or derive surveyed coordinates from them.
