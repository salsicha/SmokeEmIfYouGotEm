# RaftSim press kit — 1.0.0-rc1

## Short description

RaftSim is a first-person whitewater guide simulation built around live shallow-water
physics, a visibly flexible inflatable raft, a responsive five-person crew, and a
continuous South Fork American campaign.

## Release facts

- Developer/publisher: SmokeEmIfYouGotEm project
- Version: 1.0.0-rc1
- Engine: Unreal Engine 5.8
- Platforms: macOS Apple Silicon and Windows x64, flat-screen single-player
- Price/source: free and open-source; code MIT, first-party content CC BY 4.0, third-party
  items governed by `CREDITS.md`, `NOTICE.md`, and source manifests
- Campaign: 49.1 km South Fork American, 20 named rapids, three flow bands
- Input: keyboard/mouse and gamepad
- Deferred beyond 1.0: VR, multiplayer, and additional river campaigns

## Core features

- Genuine packaged finite-volume water simulation rather than presentation playback.
- Local raft compression, buckling, wrap, pin, capsize, damage, and recovery.
- Guide calls, scouting, crew timing, swimming, throw-line and reach rescue, progression,
  training, Free Run, accessibility, saved settings, and route review.
- DEM/imagery-conditioned geography with deterministic, explicitly labelled procedural
  infill where authoritative detail is unavailable.

## Media policy

Only captures listed in `media-manifest.json` may be distributed as game screenshots or
trailer frames. They must come from the release-candidate executable, disclose procedural
geography where relevant, and may not imply surveyed navigational accuracy. Generated
concept art and third-party link-only references are not gameplay screenshots.

Final store capsules, approved RC screenshots, and the in-engine trailer remain gated on
the M10 art/rights acceptance pass. This directory intentionally does not relabel earlier
development captures as release media.
